# 🚗 Sistema de Aluguel de Carros

Sistema web desenvolvido para a disciplina de **Software Products**, simulando o funcionamento de uma locadora de veículos. O projeto integra **Front-End**, **Back-End** e **Banco de Dados** por meio de uma API REST.

## 🎯 Funcionalidades

- Cadastro e login de usuários
- Cadastro e exclusão de carros
- Pesquisa e filtro de veículos
- Verificação de disponibilidade
- Aluguel e devolução de carros
- Avaliação de veículos
- Visualização das reservas do usuário
- Dashboard com indicadores do sistema
- Exportação do dashboard para Excel com gráfico

## 🧰 Tecnologias Utilizadas

- **Front-End:** HTML, CSS e JavaScript
- **Back-End:** Python e Flask
- **Banco de Dados:** MySQL (Workbench)
